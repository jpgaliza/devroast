# devroast v0.1.0 - First Public Release

devroast is a web app for developers who want fast, honest, and sometimes brutal feedback on their code.
This first release delivers the core experience end to end, from code submission to AI-generated review, score, and sharing.

## What devroast offers

- Paste code and get an AI review in seconds
- Toggle between constructive mode and roast mode
- Receive a score, verdict, and actionable feedback
- Explore a public leaderboard of the most roasted code
- Share results through a dedicated share page

## Core highlights

- Modern full-stack architecture with Next.js App Router
- Type-safe API layer with tRPC and schema validation
- PostgreSQL persistence with Drizzle ORM
- Reusable UI component system with consistent styling patterns
- Token-based theming and terminal-inspired visual identity
- Syntax highlighting and polished result presentation
- Dynamic metadata and social sharing support
- Updated project documentation and architecture decisions recorded in ADRs

## Stability and quality baseline

- Route organization cleaned and consolidated
- Duplicate and outdated structures removed
- Consistent component naming and class composition patterns
- Production-oriented setup for local development and database workflow
- Foundation prepared for future improvements like deeper analytics, more sharing options, and feature expansion
